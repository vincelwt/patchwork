Patchwork

Support

Help with the Patchwork mobile app, device pairing, and workspace access.

Need help from a person?

Open a GitHub support issue. Do not include pairing codes, access tokens, private messages, or confidential files.

Pair a phone or tablet

  1. Open the workspace in Patchwork Desktop.
  2. Open Settings, choose Remote, then choose Show pairing code.
  3. In the mobile app, choose Scan pairing code and scan the code within five minutes.

Each mobile device receives its own revocable key. The QR code is single-use and does not contain your existing Desktop key.

Connection problems

  • Confirm that the relay is online and reachable from the phone over HTTPS.
  • For a self-hosted relay, confirm its public URL and TLS certificate are valid.
  • If the app says access was removed, pair the device again or ask a workspace administrator to check Members and paired devices.
  • Offline data is read-only. Reconnect before sending messages or changing workspace data.

Lost or replaced device

On another signed-in device, open Settings or Members and revoke the lost device. Signing out removes the local credential, saved workspace data, drafts, and cached images. If the relay is offline during sign-out, revoke the old key later from another device.

Privacy, data, and AI providers

Your workspace administrator controls membership, retention, configured AI agents, and model providers. Contact that administrator for data access, correction, export, or deletion requests and to learn which providers can receive workspace content. See the privacy policy for details.

Security reports

Report vulnerabilities privately through GitHub Security. Never post credentials or sensitive workspace data in a public issue.
